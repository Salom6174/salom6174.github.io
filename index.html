⚙️ A Few Settings Worth Knowing

Keeping transparency

PNG is one of the few common image formats that supports see-through areas. If your source file has a transparent background, img2png preserves it. Converting back out of PNG into JPEG later would flatten it, so keep the PNG if transparency matters.

File size versus quality

PNG files are usually larger than JPEG files, because nothing is discarded to shrink them. That is the trade-off you are accepting in exchange for a perfect copy. For screenshots, logos, diagrams and images containing text, PNG is almost always the better choice; for large photo albums, JPEG often stays smaller.

Converting a whole folder

If you have dozens of images, choose the folder option rather than selecting files one by one. img2png will work through them and write a PNG for each into the destination you picked, keeping the original file names.
